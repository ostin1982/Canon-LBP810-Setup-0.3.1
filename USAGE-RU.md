# Печать из приложений Windows — версия 0.3

## На этом компьютере

Очередь называется **Canon LBP-810 (USB)**. Выбирайте её в Word, браузере, просмотрщике PDF или другом приложении и печатайте обычным способом.
Принтер должен быть включён и подключён по USB. Формат — **A4**, печать односторонняя, чёрно-белая, 600 dpi.

В области уведомлений работает Lbp810Bridge. Он автоматически запускается при входе текущего пользователя в Windows. Если вы закрыли программу, запустите `Start-Bridge.cmd`.
Не перемещайте и не удаляйте папку программы после установки: автозапуск ссылается на неё.

## Установка из архива на другом компьютере

1. Распакуйте весь архив в постоянную папку.
2. Запустите `Install.cmd`. Если Windows отказала в доступе, повторите от имени администратора.
3. Должен быть включён штатный компонент Windows «Печать в PDF (Майкрософт)» / Microsoft Print to PDF. Установка сообщит, если его нет.
4. Выберите **Canon LBP-810 (USB)** в меню печати.

Внешние программы, Linux и виртуальная машина не требуются. Используются встроенный подписанный драйвер Microsoft Print To PDF, встроенный PDF-компонент Windows и наш проверенный USB-модуль. Наша программа не требует отключать проверку подписей драйверов.

## Что проверено

- Ранее на самом LBP-810 напечатана тестовая страница через USB; принтер подтвердил `Printed=1`, ошибок контроллера и двигателя не было.
- В версии 0.3 создана реальная очередь Windows, через неё приняты два двухстраничных задания от System.Drawing.PrintDocument.
- Каждая страница преобразована в растр A4 4960×7014. Текст на русском и линии просмотрены в результатах рендеринга.
- Повреждённый входной документ отклонён.
- Пользователь подтвердил успешную печать документов после снятия блокировки Raster.dll. Исправление включено в установку пакета 0.3.1.

## Ограничения и ошибки

Если журнал содержит `Add-Type`, `Raster.dll` и `0x80131515`, Windows заблокировала DLL как скачанный файл. Запустите `Repair-Blocked-DLL.cmd` из той же папки, где лежит Raster.dll. Он проверит SHA-256 исходной версии 0.3, снимет отметку скачивания только с этой DLL и проверит загрузку. При `REPAIR OK` отправьте одну новую страницу из приложения. Очередь переустанавливать не нужно, старые неуспешные задания автоматически не повторяются.

- Эта версия предназначена для A4; другие размеры вписываются в A4 с сохранением пропорций. Автоматического дуплекса нет.
- Программа должна работать в сеансе текущего пользователя. Совместная сетевая печать и печать из чужого сеанса не настроены.
- В очереди Windows задание может исчезнуть после передачи нашей программе, раньше фактического выхода бумаги. Окончательный результат смотрите в журнале программы.
- Если принтер отключён или произошла ошибка, задание помечается как неуспешное. Автоматического повторения нет, чтобы не напечатать уже вышедшие страницы ещё раз. Устраните причину, проверьте вышедшие листы и отправьте нужные страницы повторно из приложения.
- После передачи задания программе отмена в очереди Windows не останавливает уже начавшуюся USB-печать. Для долгих документов лучше сначала проверить небольшое задание.
- Лимит PDF-задания — 100 МБ и 500 страниц. Большой документ разбейте на части.

`Open-Logs.cmd` открывает папки заданий. Для диагностики пришлите `state.txt` и `print.log` из последней папки. Общий журнал: `%LOCALAPPDATA%\Lbp810Bridge\bridge.log`.
При успешной обычной печати временные PDF и растры удаляются. При ошибке они сохраняются для диагностики; они могут содержать ваш документ. Их можно удалить после разбора ошибки.

Удаление очереди и автозапуска: завершите программу через её значок и запустите `Uninstall.cmd`. Исходники и журналы автоматически не удаляются. Другие принтеры и исходная очередь Microsoft Print to PDF не меняются.

## Сборка

Исходники находятся в `src/`. `build.ps1 -Compiler C:/path/to/llvm-mingw/bin/clang++.exe` собирает USB-программу, Raster.dll и приложение Lbp810Bridge. Нужны LLVM-MinGW с C++23 и штатный компилятор .NET Framework Windows.

Схема: приложение → подписанный Microsoft Print To PDF → локальный TCP-порт 127.0.0.1:18100 → Lbp810Bridge → Windows PDF API → растр A4/SCoA → USB LBP-810.
TCP-обработчик доступен только на этом компьютере, из сети к нему подключиться нельзя.
