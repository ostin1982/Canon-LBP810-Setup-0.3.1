# Canon LBP-810 — USB-печать в Windows 11

**Версия установочного пакета: 0.3.1.** Программы печати — версия 0.3 с исправлением установки скачанной DLL.

Пакет позволяет печатать на Canon LBP-810 по обычному USB-кабелю из Word, браузера, просмотрщика PDF и других приложений Windows. После установки в списке принтеров появляется **Canon LBP-810 (USB)**.

Это неофициальная разработка. Она использует встроенный подписанный драйвер Microsoft Print To PDF, встроенный PDF-компонент Windows и USB-модуль на основе открытой библиотеки libcapt. Виртуальная машина для работы не требуется.

## Быстрый старт

1. Полностью распакуйте архив в постоянную папку, например `C:\Canon-LBP810`.
2. Подключите LBP-810 по USB, включите его и положите бумагу A4.
3. Запустите **Install.cmd** из распакованной папки.
4. Дождитесь сообщения **INSTALLATION OK**.
5. Откройте документ, выберите **Canon LBP-810 (USB)** и отправьте одну страницу для проверки.

Не запускайте установку прямо из окна ZIP-архива. Все файлы пакета должны находиться рядом. После установки сохраняйте папку на прежнем месте: программа и её автозапуск используют этот путь.

## Требования

| Компонент | Требование |
| --- | --- |
| Компьютер | Windows 11 x64, Intel/AMD |
| Принтер | Canon LBP-810 |
| Подключение | USB-кабель, желательно напрямую к компьютеру |
| Компоненты Windows | Microsoft Print to PDF, Windows PowerShell 5.1, .NET Framework и Windows PDF API |
| Бумага | A4 |
| Режим | Чёрно-белая, односторонняя печать, 600 dpi |

Работа на Windows ARM, других операционных системах и других моделях принтеров не подтверждена. Драйверы LBP8100 и других похожих по названию моделей этому устройству не соответствуют.

## Установка на другом компьютере

### 1. Подготовьте файлы

Скопируйте ZIP на нужный компьютер и распакуйте **всё содержимое**. Найдите папку, в которой одновременно лежат:

- `Install.cmd` и `Install.ps1`;
- `Lbp810Bridge.exe` и `Lbp810Usb.exe`;
- `Raster.dll` и `Render-Job.ps1`.

Не переносите только один EXE или CMD: программе нужны остальные компоненты.

### 2. Запустите установку

Дважды щёлкните `Install.cmd`. Если получен отказ в доступе, закройте окно и повторите через правую кнопку мыши → **Запуск от имени администратора**.

Установщик:

1. Проверяет наличие основных файлов.
2. Проверяет SHA-256 исходной `Raster.dll`, снимает её отметку скачивания и проверяет загрузку.
3. Проверяет доступность Windows PDF API и штатного драйвера Microsoft Print To PDF.
4. Создаёт локальный порт `CanonLBP810_Local_18100` для `127.0.0.1:18100`.
5. Создаёт очередь **Canon LBP-810 (USB)** и задаёт A4, одностороннюю печать.
6. Запускает обработчик и добавляет его ярлык в автозапуск текущего пользователя.

Сообщения сохраняются в `install-result.txt` рядом с установщиком. Завершение с ошибкой обозначается **INSTALLATION FAILED**; успешное — **INSTALLATION OK**.

### 3. Если отсутствует Microsoft Print to PDF

1. Нажмите `Win+R`.
2. Введите `optionalfeatures` и нажмите Enter.
3. Включите **Печать в PDF (Майкрософт)** / **Microsoft Print to PDF**.
4. Дождитесь установки компонента, выполните перезагрузку, если Windows её запросит.
5. Снова запустите `Install.cmd`.

### 4. Если обработчик уже запущен

Установщик предложит сначала завершить Lbp810Bridge. Дождитесь окончания печати, найдите его значок в области уведомлений рядом с часами и выберите **Exit (pauses document printing)**. Затем повторите установку.

Не завершайте программу во время обработки документа.

## Ежедневная печать

1. Включите принтер и проверьте USB-подключение.
2. Убедитесь, что Lbp810Bridge работает: его значок находится в области уведомлений Windows.
3. В приложении откройте меню печати и выберите **Canon LBP-810 (USB)**.
4. Используйте A4. Для первой проверки выберите одну страницу и одну копию.

При входе пользователя в Windows обработчик запускается автоматически. Если вы его закрыли, запустите `Start-Bridge.cmd`. Закрытие чата не останавливает программу печати.

Обработчик работает в сеансе пользователя, выполнившего установку. Печать из других пользовательских сеансов и общий сетевой доступ не настроены.

## Как проходит задание

```text
Word / браузер / другое приложение
  → штатный Microsoft Print To PDF
  → локальный порт 127.0.0.1:18100
  → Lbp810Bridge
  → Windows PDF API
  → чёрно-белые страницы A4, сжатие SCoA
  → прямая передача по USB в LBP-810
```

Обработчик принимает подключения только с этого компьютера. Страницы документа обрабатываются последовательно.

Очередь Windows может освободиться раньше, чем выйдет бумага: после передачи документа обработка продолжается в Lbp810Bridge. Окончательный результат находится в журнале задания.

## Диагностика

### Принтер не появился в меню приложения

Посмотрите `install-result.txt`. При необходимости повторите установку. Полная проверка очереди выполняется через `Diagnose-Queue.cmd`.

### Очередь есть, но лист не выходит

1. Проверьте питание, бумагу и USB-кабель.
2. Убедитесь, что обработчик запущен. При необходимости используйте `Start-Bridge.cmd`.
3. Запустите `Diagnose-Queue.cmd` из папки программы.
4. Откройте последнюю по времени папку задания через `Open-Logs.cmd`.

Для разбора ошибки сохраните:

- `diagnostic-queue.txt` — очередь, порт, процесс и последние журналы;
- `state.txt` — состояние конкретного задания;
- `print.log` — подробная ошибка обработки или печати;
- `bridge.log` — общий журнал, если он нужен дополнительно.

Содержимое документа обычно не требуется для первого разбора ошибки.

### Ошибка Raster.dll / Add-Type / 0x80131515

Это обнаруженная проблема загрузки DLL после скачивания. Пакет 0.3.1 учитывает её при установке.

Если ошибка всё же появилась:

1. Найдите папку с `Raster.dll` и `Lbp810Bridge.exe`.
2. Запустите **Repair-Blocked-DLL.cmd именно из этой папки**.
3. Дождитесь **REPAIR OK**.
4. Отправьте одну **новую** страницу из приложения.

Исправление проверяет SHA-256 исходной DLL и снимает отметку скачивания только с неё. Результат сохраняется в `repair-result.txt`.

Сообщение `Put this CMD in the program folder...` означает, что CMD лежит не рядом с DLL. Сообщение о несовпадении хеша означает, что файл отличается от проверенной версии; исправление его не разблокирует.

### USB-принтер не обнаружен

`Present USB printer interfaces: 0` означает, что программа не видит подключённого USB-принтера. Проверьте питание, переподключите кабель и попробуйте другой USB-порт. Для отдельной проверки связи запустите `Diagnose.cmd`.

### Старое задание осталось неуспешным

Автоматического повторения нет. Устраните причину, проверьте уже вышедшие листы и повторно отправьте из приложения только нужные страницы. Перезапуск программы не перепечатывает неуспешные задания.

## Где находятся журналы

```text
%LOCALAPPDATA%\Lbp810Bridge\bridge.log
%LOCALAPPDATA%\Lbp810Bridge\jobs\<папка задания>\state.txt
%LOCALAPPDATA%\Lbp810Bridge\jobs\<папка задания>\print.log
```

`Open-Logs.cmd` открывает папки заданий. Двойной щелчок по значку обработчика также открывает их.

После успешной обычной печати временные PDF и растры удаляются. При ошибке они сохраняются для диагностики и могут содержать сам документ. После разбора ошибки ненужные папки заданий можно удалить, предварительно убедившись, что они больше не обрабатываются.

## Ограничения

- Печать A4, чёрно-белая, 600 dpi, односторонняя.
- Другие размеры страниц вписываются в A4 с сохранением пропорций.
- Лимит одного принятого PDF-задания: 100 МБ и 500 страниц.
- Windows может считать задание переданным до физического завершения печати.
- Отмена в очереди Windows после передачи документа обработчику не останавливает уже начавшуюся USB-печать.
- Нет автоматического повторения задания после ошибки.
- Программа должна работать в сеансе пользователя; фоновая системная служба не устанавливается.
- Общая сетевая печать, работа из других сеансов и автоматический дуплекс не реализованы.

## Перенос папки и переустановка

Для нового компьютера используйте исходный ZIP и выполните установку заново.

Чтобы переместить папку на том же компьютере:

1. Дождитесь окончания заданий.
2. Завершите Lbp810Bridge через значок в области уведомлений.
3. Переместите **всю** папку программы.
4. Запустите `Install.cmd` из нового места, чтобы обновить путь автозапуска.

## Удаление

1. Дождитесь завершения печати и очистки очереди.
2. Завершите обработчик через его значок.
3. Запустите `Uninstall.cmd`; при отказе в доступе повторите от имени администратора.
4. После удаления при необходимости вручную удалите папку программы и ненужные журналы.

Удаляются принадлежащие программе очередь, порт и ярлык автозапуска. Другие принтеры и исходная очередь Microsoft Print to PDF сохраняются. Если в очереди остались задания, удаление останавливается до их завершения или отмены.

## Проверенная работа и изменения

- В версии 0.2 пользователь подтвердил выход тестового листа по USB; принтер сообщил `Printed=1` без ошибок двигателя и контроллера.
- Для версии 0.3 проверены приём многостраничных заданий реальной очередью Windows и преобразование страниц, включая русский текст.
- На другом компьютере обнаружена блокировка скачанной `Raster.dll` с `0x80131515`. Ошибка воспроизведена на тестовой копии и исправлена.
- После исправления пользователь подтвердил успешную печать из приложения.
- Пакет 0.3.1 сохраняет рабочие исполняемые программы, включает исправление в установщик и добавляет инструкции и журнал установки.
- Проверка установщика с искусственно добавленной отметкой скачивания DLL прошла. Она не меняла очередь или автозапуск рабочего компьютера.

Эти результаты подтверждают работу на проверенном оборудовании, но не являются сертификацией для всех конфигураций Windows.

## Для разработчиков

Для обычной установки сборка не нужна. Готовые EXE и DLL уже находятся в архиве.

Для сборки исходников требуются LLVM-MinGW с поддержкой C++23 и штатный компилятор .NET Framework Windows. Проверенная версия инструментария: `llvm-mingw-20260311-ucrt-x86_64`.

Из папки программы:

```powershell
.\build.ps1 -Compiler 'C:\tools\llvm-mingw\bin\clang++.exe'
```

Скрипт собирает USB-модуль, запускает его автономные проверки, затем собирает `Raster.dll` и `Lbp810Bridge.exe`. Перед пересборкой завершите работающий обработчик и используйте отдельную рабочую копию пакета.

Установщик и исправление блокировки закреплены за SHA-256 поставляемой `Raster.dll`. После собственной пересборки её хеш может измениться: проверьте результат сборки и обновите ожидаемый хеш в `Install.ps1` и `Repair-Blocked-DLL.cmd`, а также список `SHA256.txt`. Поставляемый установщик намеренно отклоняет отличающуюся DLL.

Проверить основные компоненты и загрузку DLL без изменения очереди и автозапуска:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -CheckOnly
```

Эта проверка снимает отметку скачивания с проверенной DLL. Она не проверяет физическую печать и не заменяет полную установку.

Разработческий `Test-Windows-Queue.ps1` создаёт двухстраничное задание. Без параметра подтверждения он проверяет, что последний запуск обработчика записан как `DryRun=True`. Параметр `-ConfirmPhysicalPrint` допускает обычную отправку двух страниц на бумагу; используйте его только намеренно.
