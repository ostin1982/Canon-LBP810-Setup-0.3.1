CANON LBP-810 — УСТАНОВКА НА WINDOWS 11 x64
Пакет 0.3.1. USB-печать, A4, 600 dpi.

1. ЧТО ЭТО

Пакет для прямой USB-печати из Word, браузера и других приложений.
Использует штатный драйвер Microsoft Print To PDF и программу Lbp810Bridge.
Виртуальная машина не нужна. Прямая печать и печать из приложения подтверждены
пользователем на Canon LBP-810. Это не официальный драйвер Canon.

В этой сборке установщик автоматически исправляет обнаруженную блокировку
Raster.dll после скачивания. Исполняемые программы сохранены из рабочей версии.

2. ПЕРЕД УСТАНОВКОЙ

Нужен компьютер с Windows 11 x64 (Intel/AMD), принтер Canon LBP-810,
USB-кабель и бумага A4.

Полностью распакуйте ZIP в ПОСТОЯННУЮ папку, например:
C:\Canon-LBP810

Не запускайте установку из окна архива. В одной папке должны находиться:
Install.cmd, Install.ps1, Lbp810Bridge.exe, Lbp810Usb.exe, Raster.dll,
Render-Job.ps1 и остальные файлы пакета.

Подключите принтер напрямую по USB и включите его.

3. УСТАНОВКА

1) Дважды щёлкните Install.cmd.
2) Дождитесь INSTALLATION OK. Установка создаёт очередь Canon LBP-810 (USB),
   запускает обработчик и добавляет его в автозапуск текущего пользователя.
3) Если получен отказ в доступе, закройте окно и запустите Install.cmd
   правой кнопкой мыши — «Запуск от имени администратора».
4) Если сообщается, что обработчик уже работает: найдите его значок
   в области уведомлений рядом с часами, откройте меню и выберите Exit.
   Затем повторите установку. Не завершайте его во время печати.

Если установщик сообщает об отсутствии Microsoft Print To PDF:
нажмите Win+R, введите optionalfeatures и нажмите Enter.
Включите «Печать в PDF (Майкрософт)» / Microsoft Print to PDF,
дождитесь установки компонента и повторите Install.cmd.
Если Windows запросит перезагрузку — сначала перезагрузите компьютер.

Все сообщения установки сохраняются рядом в install-result.txt.

4. КАК ПЕЧАТАТЬ

Откройте документ → «Печать» → выберите Canon LBP-810 (USB).
Для первой проверки отправьте одну страницу A4, одну копию.

Программа Lbp810Bridge должна работать в сеансе того пользователя,
который выполнял установку. При следующем входе в Windows она запустится сама.
Если вы её закрыли, запустите Start-Bridge.cmd.

Не перемещайте папку после установки: автозапуск ссылается на неё.
При переносе сначала завершите обработчик через его значок,
переместите всю папку и снова запустите Install.cmd из нового места.

5. ЕСЛИ НЕ ПЕЧАТАЕТ

А. Принтер отсутствует в списке приложения:
проверьте результат Install.cmd. Запустите Diagnose-Queue.cmd.

Б. Принтер есть, но лист не выходит:
проверьте питание, USB, бумагу и запуск Lbp810Bridge.
Запустите Diagnose-Queue.cmd и сохраните diagnostic-queue.txt.

В. Ошибка Raster.dll / Add-Type / 0x80131515:
запустите Repair-Blocked-DLL.cmd ИМЕННО из папки с Raster.dll.
После REPAIR OK отправьте одну НОВУЮ страницу.
В обычной новой установке эту проблему уже устраняет Install.cmd.

Г. Нужны подробности задания:
Open-Logs.cmd открывает папки заданий. В последней по времени папке
находятся state.txt и print.log. Их вместе с diagnostic-queue.txt
достаточно для первого разбора. Сам документ присылать не обязательно.

Старые неуспешные задания автоматически не повторяются.
После устранения ошибки отправьте нужные страницы заново из приложения.

6. ВАЖНЫЕ ОСОБЕННОСТИ

— Печать чёрно-белая, A4, односторонняя. Другие форматы вписываются в A4.
— Очередь Windows может освободиться до выхода бумаги: обработка продолжается
  в нашей программе. Итог находится в print.log.
— Отмена в очереди Windows после передачи задания обработчику не останавливает
  уже начавшуюся USB-печать.
— Общая сетевая печать и другие сеансы пользователей не настроены.
— Лимит одного задания: 100 МБ PDF и 500 страниц.
— При успехе временные документы удаляются; при ошибке остаются в локальной
  папке %LOCALAPPDATA%\Lbp810Bridge\jobs для диагностики.

7. УДАЛЕНИЕ

Дождитесь окончания заданий, завершите Lbp810Bridge через значок рядом с часами,
запустите Uninstall.cmd. При отказе в доступе — от имени администратора.
Удаляются наша очередь, её порт и наш ярлык автозапуска.
Папку программы и журналы при необходимости удалите вручную после завершения
обработчика. Другие принтеры остаются на месте.

8. СОСТАВ ПАКЕТА

Install.cmd             установка
Start-Bridge.cmd        запуск обработчика
Diagnose-Queue.cmd     полная диагностика
Diagnose.cmd           диагностика USB
Open-Logs.cmd          журналы заданий
Repair-Blocked-DLL.cmd исправление блокировки Raster.dll
Uninstall.cmd          удаление очереди и автозапуска
Print-Test.cmd         отдельная прямая тестовая печать одного листа
src, vendor, build.ps1 исходники и сборка
vendor\libcapt\LICENSE лицензия библиотеки libcapt

Храните этот ZIP как резервную копию для установки на другом компьютере.
